# 物联网题库

物联网通信技术章节测验 2、3、4 合并复习站，共 **185 题**。

## 功能

- 85 道单选题、83 道判断题、10 道简答题、7 道分析题
- 按题库、题型和复习状态筛选
- 题干、选项、答案与知识点的全文搜索
- 客观题即时判分，主观题可自评掌握状态
- 随机抽取 10 题
- 错题本、题目收藏和参考答案
- 学习进度、笔记只保存在访问者自己的浏览器中
- 桌面、平板和手机自适应，支持深色模式

## 本地预览

```powershell
cd iot-question-bank
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。

## 更新题库

1. 用新的 Markdown 内容替换 `sources/` 下的对应文件，保持题目标题、选项、答案和解析结构。
2. 运行数据构建脚本：

```powershell
node .\scripts\build-data.mjs
```

脚本会校验三套题库的总题数、答案与选项一致性，并生成 `data/questions.json`。

## 技术说明

项目是无构建依赖的静态站点，使用原生 HTML、CSS 和 JavaScript。直接部署仓库根目录至 GitHub Pages 即可运行。
